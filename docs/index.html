Features

One job, done well.

A small menu bar app that does multi-item copy and paste and nothing else.

Two global hotkeys

Toggle queue mode with Control-Option-C and paste the next item with Control-Option-V. Both can be re-recorded in Settings, with a warning if a shortcut is unavailable.

FIFO, LIFO or paste all

Paste oldest-first or newest-first, or paste the whole queue at once joined by a newline, comma, tab, space or semicolon.

Fill forms with auto-advance

Optionally send a Tab keypress after each paste so values land in successive fields. Text, files and images can all be queued.

Menu bar queue you can edit

See queued items with the next one marked by an arrow. Drag to reorder, delete single items or clear the queue. A brief HUD confirms each copy and paste.

Careful with sensitive data

Concealed, transient and auto-generated pasteboard types such as password manager copies are ignored. Items over 1 MB are skipped and the queue is capped at 200.

Survives crashes and restarts

The queue is mirrored to a small JSON file, and your original clipboard can be restored when the queue empties. Launch at login is optional.

Install

Up and running in a minute.

PasteStackQueue is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download PasteStackQueue-macOS.zip and unzip it.
  2. Move PasteStackQueue.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/PasteStackQueue.app
  4. When you first paste, grant Accessibility in System Settings Privacy Security Accessibility so the app can send the Command-V keystroke.

FAQ

Questions, answered.

Is PasteStackQueue really free and open source?

Yes. It is released under the MIT license, with no accounts, no ads and no paid tier. The full source is on GitHub, and a donation link is there if you want to support development.

What permissions does it need?

Only Accessibility, which is used to send Command-V (and the optional Tab) to the frontmost app. Without it, the paste hotkey still places the next item on your clipboard and you press Command-V yourself. The app has no network access.

Where is my data stored?

Only on your Mac. While the queue has items, it is mirrored to a small JSON file in ~/Library/Application Support/PasteStackQueue/ so a crash does not lose it. Nothing is sent anywhere.

Why isn't the app notarized?

Notarization requires a paid Apple Developer account, and this is a free project. Right-click the app and choose Open once to launch it, or build it yourself from source with Xcode.

Was this written by AI?

Yes. It has had less human review than a hand-written app, so bug reports are welcome.
